# skills-src

Source copies of Big Coach's claude.ai account skills that don't load from
this repo (so they don't duplicate the account versions). To update one:
edit here, zip the folder (`zip -r name.zip name`), and upload it in
claude.ai settings under Skills.

- `big-coach-video-editor/`: the video editor, with `scripts/`
  (face_safe.py, qa_sheet.py, final_check.py).

The project skills in `.claude/skills/` (big-coach-humanizer,
big-coach-edit-styles) load automatically in this repo and are also
uploaded to the account.
